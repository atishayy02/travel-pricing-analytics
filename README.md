# Travel Pricing Intelligence Dashboard (India)

This project analyzes end-to-end travel costs across Indian destinations, including stay, transport, food, and activities.

## Features
- Cost modeling across destinations and seasons
- Power BI dashboard for visualization
- Recommendation logic for budget-based travel
- Value analysis using cost vs rating

## Key Insight
Mid-cost trips (~₹12K–₹16K) offer the best value based on user ratings.

## Tools Used
Python, Pandas, Power BI
